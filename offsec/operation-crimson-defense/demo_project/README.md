# Markdown Editor (macOS)

A simple SwiftUI macOS Markdown editor with a live preview pane.

## Features
- Type Markdown in the left pane.
- Live HTML preview in the right pane.
- Clean SwiftUI layout using HStack and WKWebView.

## Running
1. Open `MarkdownEditor.xcodeproj` in Xcode.
2. Build and run the app.
3. Type Markdown on the left and watch the preview update.
